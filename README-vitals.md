# מידע חיוני — לוח בריאות אישי

אפליקציית דף אחד (`vitals.html`) בעברית, שמרכזת את נתוני הבריאות והכושר שלך:
צעדים, קלוריות, מרחק, דקות פעילות, דופק, שינה, משקל, אחוז שומן, לחץ דם, סוכר, ריווי חמצן ושתייה.

הכול רץ בדפדפן בלבד — אין שרת, אין בסיס נתונים, והנתונים נשמרים מקומית ב-`localStorage`.

## הפעלה

* **מקומית:** מורידים את `vitals.html` ופותחים בדפדפן. (לסנכרון מול גוגל נדרש אתר אמיתי — ראו למטה.)
* **דרך GitHub Pages:** מפעילים Pages על הרפו (Settings → Pages → Deploy from branch),
  והאפליקציה תהיה זמינה בכתובת `https://<user>.github.io/<repo>/vitals.html`.

## שלוש דרכים להכניס נתונים

1. **סנכרון ישיר מ-Google Fit** — לשונית "סנכרון וייבוא": מזינים Client ID של OAuth ולוחצים התחברות.
   ⚠️ גוגל סגרה את ה-API של Fit למפתחים חדשים (מאי 2024) והשירות בכיבוי במהלך 2026,
   לכן המסלול הזה יעבוד רק בפרויקט Google Cloud שבו ה-Fitness API כבר מופעל.
2. **ייבוא קובץ** — גוררים לאזור הייבוא קובץ ZIP של [Google Takeout](https://takeout.google.com)
   (מסמנים רק Fit / Health Connect), או קובצי CSV/TSV. הקריאה מתבצעת בדפדפן, בלי העלאה לשום מקום.
   מזוהות אוטומטית כותרות באנגלית ובעברית, כולל המרות יחידות (מטרים→ק"מ, מילישניות→שעות וכו').
3. **רישום ידני** — לשונית "יומן", לכל מדד ותאריך.

## יכולות

* לוח מחוונים עם טבעת יעד, מגמות מול התקופה הקודמת וגרפי סְפַּארְק לכל מדד.
* מסך מגמות עם גרפי עמודות/קו לכל מדד, קו יעד וסטטיסטיקות.
* יעדים אישיים (צעדים, שינה, קלוריות, שתייה, דקות פעילות) וחישוב BMI לפי גובה.
* מצב כהה/בהיר, ממשק RTL מותאם לנייד.
* גיבוי וייצוא: JSON (גיבוי מלא הניתן לשחזור) ו-CSV.
* נתוני הדגמה בלחיצה אחת, כדי לראות את המערכת לפני חיבור נתונים אמיתיים.

## פרטיות

שום נתון לא נשלח לשרת של האפליקציה — אין כזה. התקשורת היחידה החוצה היא מול שרתי גוגל
בזמן סנכרון, עם אסימון שנשמר ב-`sessionStorage` ופג אחרי כשעה.
מחיקת נתוני הדפדפן תמחק את ההיסטוריה — כדאי לשמור גיבוי JSON מדי פעם.

האפליקציה מיועדת למעקב אישי ואינה מהווה ייעוץ או אבחון רפואי.
