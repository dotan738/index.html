    ☁️ גיבוי אוטומטי בענן

    כשזה מופעל, כל שינוי באוסף (כולל התמונות) נשמר אוטומטית בגיבוי סודי בחשבון GitHub שלך. אם מחליפים או מאבדים טלפון – מכניסים את אותו מפתח ולוחצים "שחזר מהענן".

    1. לחץ כאן ליצירת מפתח ב-GitHub (רק הרשאת gist מסומנת)
    2. בחר תוקף ("Expiration") – למשל No expiration – ולחץ Generate token
    3. העתק את המפתח והדבק כאן
