סנכרון מ-Google Fit

שימו לב: גוגל סגרה את ה-API של Google Fit למפתחים חדשים (מ-1 במאי 2024) והשירות בתהליך כיבוי במהלך 2026. הסנכרון הישיר יעבוד רק אם יש לך פרויקט ב-Google Cloud שבו ה-Fitness API כבר מופעל. אם הסנכרון נכשל — אפשר לייבא את כל ההיסטוריה דרך Google Takeout למטה, וזו גם הדרך היציבה לטווח ארוך.
מקור מורשה להוספה ב-Google Cloud
סנכרון אחרון—
טווח משיכה
איך מפיקים Client ID (מדריך קצר)
  1. נכנסים ל-console.cloud.google.com ובוחרים פרויקט קיים שבו ה-Fitness API מופעל.
  2. ב-APIs & Services → Credentials יוצרים OAuth client ID מסוג Web application.
  3. תחת Authorized JavaScript origins מוסיפים את המקור המוצג למעלה.
  4. במסך ההסכמה (OAuth consent screen) מוסיפים את כתובת המייל שלך כ-Test user.
  5. מעתיקים את ה-Client ID לשדה שלמעלה ולוחצים "התחברות".

האסימון נשמר בזיכרון הדפדפן בלבד (sessionStorage) ופג אחרי כשעה. שום נתון לא נשלח לשרת חיצוני — הכול נשאר במכשיר.

ייבוא קובץ

Takeout · Health Connect · CSV · גיבוי
📥 גוררים לכאן קובץ, או בוחרים קובץ מהמכשיר
נתמכים: ZIP של Google Takeout, קובצי CSV/TSV של Fit או Health Connect, ו-JSON של גיבוי מהאפליקציה
איך מורידים את הנתונים מ-Google Takeout
  1. נכנסים ל-takeout.google.com עם אותו חשבון גוגל.
  2. לוחצים "בטל בחירת הכול" ומסמנים רק את Fit (או Health Connect, אם קיים).
  3. מייצאים בפורמט ZIP וממתינים למייל עם הקישור.
  4. מורידים את ה-ZIP וגוררים אותו לכאן — האפליקציה תקרא את התיקייה Daily activity metrics ותוסיף את כל הימים.

הקובץ נקרא מקומית בדפדפן ואינו מועלה לשום מקום.

פרטיות

כל הנתונים נשמרים מקומית בדפדפן שלך (localStorage) ואינם נשלחים לשום שרת. התקשורת היחידה החוצה היא ישירות מול שרתי גוגל בזמן סנכרון, עם אסימון שנשמר לזמן קצוב בלבד. מחיקת היסטוריית הדפדפן או שימוש בגלישה פרטית ימחקו את הנתונים — כדאי לשמור גיבוי JSON מדי פעם.

האפליקציה נועדה למעקב אישי בלבד ואינה מהווה ייעוץ, אבחון או המלצה רפואית.
