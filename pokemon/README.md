# הפוקדקס של ניתאי עשור

אפליקציית ווב (עובדת בטלפון) לניהול אוסף קלפי פוקימון.

## מה יש באפליקציה
- **📚 האוסף שלי** – כל הקלפים, כמות, שווי כל קלף ושווי האוסף בשקלים. חיפוש, מיון, עדכון מחירים, גיבוי.
- **➕ הוסף קלף** – מצלמים את הקלף, האפליקציה מוצאת את הקצוות ומיישרת את התמונה, קוראת את שם הקלף והמספר (OCR),
  מחפשת במאגר הקלפים ומשווה לתמונה. בוחרים את הקלף המתאים והוא נכנס לאוסף.
- **💰 כמה זה שווה?** – אותו תהליך סריקה, עם הערכת שווי לפי סוג הקלף (רגיל/הולו/רוורס) ומצב הקלף.

## מקורות המידע
| מקור | מה נלקח ממנו |
|---|---|
| [Pokémon TCG API](https://pokemontcg.io) | מאגר הקלפים, תמונות רשמיות, מחירי TCGplayer ($) ו-Cardmarket (€) |
| [TCGdex](https://tcgdex.dev) | מאגר גיבוי עם מחירים, אם הראשי לא זמין |
| [ExchangeRate-API](https://www.exchangerate-api.com) | שער דולר/אירו לשקל |
| OpenCV.js | זיהוי הקצוות של הקלף בתמונה |
| Tesseract.js | קריאת הטקסט על הקלף |
| Claude API (אופציונלי) | זיהוי חכם ומדויק יותר, עם מפתח API שמוכנס בהגדרות |

השווי המשוער = ממוצע מחיר השוק ב-TCGplayer ומגמת המחיר ב-Cardmarket, מומר לשקלים ומוכפל במקדם לפי מצב הקלף
(NM 100%, LP 85%, MP 70%, HP 50%, פגום 30%).

## הפעלה
זה דף HTML סטטי – אפשר לפרסם ב-GitHub Pages (או כל אחסון HTTPS). המצלמה החיה דורשת HTTPS.
בטלפון: לפתוח את הקישור ← "הוסף למסך הבית" כדי שיופיע כאפליקציה.
הנתונים נשמרים בדפדפן של הטלפון (IndexedDB) – מומלץ לגבות מדי פעם דרך ההגדרות.
